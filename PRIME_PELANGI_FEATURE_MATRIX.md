# PRIME vs Pelangi Accounting — Feature Coverage Matrix

Source: `PRIME-Integrated Facility&Property Mgt System Solution-PRIME-2025.pdf` (see `pdf.md`)  
Apps compared:

- **Accounting** → `PELANGI-ACCOUNTING/` (Laravel + Filament)
- **Inventory** → `inventory/` (Laravel API — project & delivery management)

**Status rules:**

- **Covered** = user-facing surface exists (Filament Resource/Page/Livewire or API route/controller). Data-layer-only (model / migration with no UI) does NOT qualify.
- **Partial** = a related feature exists but does not fully match PRIME's scope.
- **Not covered** = no user-facing feature in either app.

## What is covered

**Accounting app** covers the full financial accounting core: GL (COA, account mapping, opening balance, journal entries), all 6 financial reports (P&L, Balance Sheet, Cash Flow, Trial Balance, General Ledger, Account Balances), full AR/AP cycle (Sales/Purchase Orders → Invoices → Returns → Aging → Payments), Cash & Bank (receipts, disbursements, transfers, advances), Fixed Assets (register, category, and all transaction types — movement, depreciation, disposal — via TransactionsRelationManager with optional auto-journal), Warehouses, Master Data (products, taxes, payment terms, contacts, business types), Users/Roles/Companies (multi-company), and Invoice sync API. It also adds a full **HR & Payroll** stack not present in PRIME (employees, attendance, leave, overtime, salary components, payroll + BCA export, THR, bonus).

**Inventory app** extends coverage with project management (Project master, PO Deposits, invoice progress), Delivery Order management (full DO lifecycle with items and delivery logs), basic inventory stock read, marketing follow-up, and bi-directional sync with the Accounting app.

## What is not covered (gaps vs PRIME)

All **property / facility management** specifics are missing: tenancy & lease contracts (all types), utility meter billing (electricity / water / gas / overtime / communication), amortization, tenant reminder / penalty / deposit, helpdesk + work orders + preventive maintenance, standalone inventory operations (warehouse transfer, stock opname, cut-off), AP draft debit notes, bank reconciliation UI, petty cash, budget management, multi-currency GL, period/yearly closing, e-Faktur, Virtual Account, Email/SMS blast, mobile apps (PRIME Mobile & PRIMO), and the full EIS dashboard suite.
